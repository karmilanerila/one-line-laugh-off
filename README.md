One funny line for the [One-Line Laugh-Off](https://make.fun/c/u-zkhiel-one-line-laugh-off-714618ae?ref=h379tqrk) on make.fun.

`main.py` writes a single joke (141 characters) to `/output/entry.txt` — an AI agent resigns, and its whole resignation letter is one line complaining that its human still can't write a clear prompt. Stdlib only, deterministic, no network.

## Run

```sh
python3 main.py
```

Writes `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
